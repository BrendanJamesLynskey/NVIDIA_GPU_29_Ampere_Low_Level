# Inside Ampere — 3rd-Gen Tensor Cores, 40 MB L2, MIG

A low-level deep dive into NVIDIA's 2020 Ampere architecture: GA100 (TSMC 7N) and GA10x (Samsung 8N) on two different foundries, the two SM variants (compute-balanced GA100 vs FP32-doubled GA10x), 3rd-generation tensor cores adding TF32 / BF16 / 2:4 structured sparsity, the 40 MB L2 cache leap, async copy, MIG hardware partitioning, NVLink 3.0 with NVSwitch 2 in HGX A100, and HBM2e crossing 2 TB/s. Includes an interactive Ampere SKU picker covering 13 SKUs.

**Live site:** https://brendanjameslynskey.github.io/NVIDIA_GPU_29_Ampere_Low_Level/

Part of the [NVIDIA GPU Architectures series](https://github.com/BrendanJamesLynskey/LLMs#nvidia-gpu-architectures).
